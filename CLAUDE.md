## Commands

```bash
bun dev          # start dev server
bun run build    # production build → dist/
bun run preview  # preview the dist/ build locally
bun run lint     # ESLint
bun run format   # Prettier (auto-fix)
```

There are no tests in this project.

## Architecture

**Stack:** React 19 SPA, TanStack Router (file-based, client-side only), Tailwind CSS v4, shadcn/ui (New York style), deployed to Vercel.

### Routing

TanStack Router with file-based routing. Routes live in `src/routes/`:
- `__root.tsx` — root layout with `<Navbar>`, `<main>`, `<Footer>`, `<WoltFloat>`
- `index.tsx` — home page (`/`)
- `meniu.tsx` — menu page (`/meniu`)
- `galerie.tsx` — photo gallery with filter + lightbox (`/galerie`)
- `contact.tsx` — contact info, map iframe, message form (`/contact`)

`src/routeTree.gen.ts` is auto-generated by the TanStack Router Vite plugin — never edit it manually.

### Entry point

`index.html` → `src/main.tsx` → mounts `<RouterProvider>` into `#root`.

### Styling

**Tailwind v4** configured in `src/styles.css` (no `tailwind.config.js`). All brand tokens are CSS custom properties defined in `:root` using `oklch()` and exposed as Tailwind utilities via `@theme inline`. Key tokens:

| Variable | Value |
|---|---|
| `--gold` | `oklch(0.74 0.14 70)` — primary brand gold |
| `--wheat` | `oklch(0.90 0.06 85)` — body text |
| `--background` | `oklch(0.16 0.02 50)` — deep brown |
| `--surface` | `oklch(0.20 0.025 55)` — card/section bg |

Custom utility classes defined in `styles.css`: `.btn-gold`, `.btn-gold-outline`, `.card-lift`, `.gold-divider`, `.ornate-frame`, `.starfield`, `.sand-grain`, `.menu-leader`.

Fonts loaded from Google Fonts: `Cinzel` (`--font-display`), `Playfair Display` (`--font-serif`), `Lato` (`--font-sans`).

### shadcn/ui

Components are in `src/components/ui/`. Add new ones with:
```bash
bunx shadcn@latest add <component>
```
The `@/` alias maps to `src/`.

### Vercel deployment

`vercel.json` sets `framework: vite`, `outputDirectory: dist`, and a catch-all rewrite to `index.html` for SPA routing. Merging to `main` triggers a new Vercel deployment automatically.
